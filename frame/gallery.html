    使用说明

    本页做什么

    浏览各个终端母版样板与视觉主题，方便在生成原型时进行引用和对照效果。在产出原型时，在对话里让 Agent 按原型技能生成到项目里。

    页面

    说清要做哪一端（WEB / 后台 / APP）和哪些页面。可点开样板页对照，让 Agent「参考某某页」来实现或增页。

    组件

    不只整页能参考：左侧「组件演示」里的基础控件、表单、图表等也可点开对照。做业务页时，可以说「交互参考某某组件样板」，Agent 会按现有组件风格落到页面里。

    主题

    WEB 和 APP 创建时先选好视觉主题（左侧「主题」）；后台默认用母版配色，只有明确要改颜色时再提。选定后增页会沿用，一般不用反复说明。

    可以这样说

    • 「做一个用户管理后台，列表参考样板里的『查询表格』。」
    • 「表单校验和提交反馈，参考『表单组件』那页的交互。」
    • 「做 WEB 落地页，主题用『亮色科技蓝』，要有价格区和 FAQ。」
    • 「现有后台别改结构，只把主色换成我们的品牌蓝。」
