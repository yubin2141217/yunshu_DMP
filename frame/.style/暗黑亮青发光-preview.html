提示卡片组

图标徽章 + 标题说明的硬边卡片，三列两行共六张。

别重复付费

同样的问题反复算 → 缓存它，别每次都花一次钱。

别为简单活付费

分类、摘要这种小活用旗舰模型 → 杀鸡用牛刀，贵几十倍。

别传没用的 token

把一堆冗余历史、长文档全塞进去 → 每个 token 都在烧钱。

能压就先压

提示词与上下文先压缩再发送 → 同样效果，少花一半量。

能批就别单跑

零散请求拆成批处理 → 摊薄固定开销，吞吐更高。

蒸馏留给最后

路径未稳就上蒸馏 → 成本砸在错误方案上，返工更贵。
