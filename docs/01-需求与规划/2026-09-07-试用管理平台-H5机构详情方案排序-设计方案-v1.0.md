# 试用管理平台 · H5机构详情产品方案列表排序设计方案

## 一、项目概述

### 1.1 背景

试用管理平台 H5「机构统计」支持销售按状态卡片下钻至机构列表，再进入机构详情查看该机构下全部产品方案。当前详情页产品方案列表未按入口意图排序，从「申请中机构」等卡片进入后，目标状态方案不一定置顶，查找成本高。

### 1.2 目标

在机构详情「产品方案」列表中：根据下钻入口状态将对应状态方案置顶，组内与其余方案均按最近写操作时间倒序，使下钻意图与列表首屏一致。

### 1.3 范围

- **端**：企业微信 H5（`mobile/`）
- **链路**：机构统计 → 机构列表 → 机构详情 · 产品方案列表
- **本期不做**：机构列表自身重排；详情卡片展示更新时间；Web 管理端同步改造（除非另立需求）

### 1.4 已确认决策

| 项 | 结论 |
|----|------|
| 入口对称 | 各状态卡片均「入口状态置顶」；机构总数仅按时间倒序 |
| 置顶集合 | 严格单状态（试用中不含即将到期；已到期不含停用） |
| 更新时间 | 方案记录最近一次写操作/保存时间 |

## 二、功能范围

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 入口状态透传 | 统计卡片 → 列表 → 详情携带 preferStatus | 🔴 |
| 产品方案列表排序 | 状态置顶 + updatedAt 倒序 | 🔴 |
| 详情查询带排序参数 | 查询机构详情时传入 preferStatus，结果已排序 | 🔴 |
| 列表页排序调整 | 本期不改 | ⚪ |
| 方案卡片展示更新时间 | 本期不改 | ⚪ |

## 三、核心模块设计

### 3.1 入口与 preferStatus

| 统计入口 | preferStatus | 置顶状态 |
|----------|--------------|----------|
| 机构总数 | 空 | 无 |
| 申请中机构 | 申请中 | 仅申请中 |
| 试用中机构 | 试用中 | 仅试用中 |
| 即将到期机构 | 即将到期 | 仅即将到期 |
| 已停止试用机构 | 已到期 | 仅已到期 |
| 冷冻期机构 | 冷冻期 | 仅冷冻期 |

机构列表进入详情时须带上当前列表的 filter（`all` 对应 preferStatus 为空）。

### 3.2 排序规则

```
若 preferStatus 为空：
  全部按 updatedAt 倒序
否则：
  组1 = status 等于 preferStatus 的方案，按 updatedAt 倒序
  组2 = 其余方案，按 updatedAt 倒序
  结果 = 组1 + 组2
updatedAt 相同：按方案标识倒序保证稳定次序
```

### 3.3 更新时间（updatedAt）

任意写操作刷新，包括但不限于：提交/审核/处理申请、开通试用、延期、关停、重置、更换产品方案、状态变更落库。

### 3.4 交互

- 详情页产品方案仍为卡片列表，点击进入方案详情（逻辑不变）
- 不新增排序切换控件；排序由入口与规则自动决定
- 直链打开详情且无 preferStatus：按机构总数规则（仅时间倒序）

## 四、数据结构与流向

### 4.1 关键字段

| 字段 | 说明 |
|------|------|
| preferStatus | 可选；申请中 / 试用中 / 即将到期 / 已到期 / 冷冻期 |
| updatedAt | 产品方案最近写操作时间 |
| status | 产品方案当前使用状态 |

### 4.2 数据流

1. 用户点击统计卡片，进入机构列表并带 filter  
2. 用户点击某机构，进入详情并带 preferStatus（由 filter 映射）  
3. 查询机构详情（含 preferStatus）  
4. 服务端按规则排序后返回产品方案列表  
5. 详情页按返回顺序展示  

---

## 五、边界情况处理

| 场景 | 处理 |
|------|------|
| 置顶组为空 | 整表按 updatedAt 倒序 |
| 无 preferStatus（机构总数或直链） | 仅按 updatedAt 倒序 |
| 机构无任何方案 | 保持现有空态提示 |
| 列表筛选口径与置顶口径不一致 | 置顶严格单状态；列表筛选口径本期不变 |
| 多端同时写导致 updatedAt 相同 | 以方案标识倒序打破平局 |

---

## 六、验收要点

1. 从「申请中机构」下钻进详情：所有「申请中」方案在顶部，组内更新时间新→旧；其余在下，按时间新→旧。  
2. 从「试用中机构」下钻：「即将到期」不进入置顶组。  
3. 从「机构总数」下钻：无状态置顶，仅时间倒序。  
4. 延期等写操作后，该方案在对应组内位置随 updatedAt 更新。
