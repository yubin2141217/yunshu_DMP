# 云数中台设计方案

## 一、项目概述

### 1.1 项目背景

云数中台是公司统一汇聚舆情等数据的入口。本期优先保证数据能汇总进入云数中台；分析统计类能力后续再规划深化。

相对 v1.2，**v1.3 明确双路径来源厂商识别**：接口推送凭 appkey；库表/JDBC 直推凭行内供数方编码。接入方案保持可复用、**不绑定供数方**。

### 1.2 建设目标

1. 运营维护字段库与接入方案库，拼装发布全局/机构标准；机构供数配置可绑定生效标准。  
2. 机构预览/下载本机构生效标准并转交供数方。  
3. 供数方按标准送数：接口带 appkey；库表行内带供数方编码；中台落库并自动打标（来源厂商、接收时间、归属机构）。  
4. 现有概览、供数统计等模块保持可用。  

### 1.3 核心价值

- 先打通「定标准 → 送数 → 落库打标」主链，来源可追溯。  
- 标准与方案可复用：一方案多标准、一标准多机构多供方。  
- 安全可控：接口凭证 + 条件 IP 白名单；库表以编码定厂商。  

### 1.4 使用端与交付

- **MT**：字段库、接入方案、标准拼装、供数方与 appkey、IP 白名单、机构供数配置（供数方 + 标准）。  
- **V8**：生效标准预览/下载；既有概览与统计。  
- **接入接收**：接口与库表两类形态（非机构操作界面）。

## 三、核心模块设计

### 3.1 数据标准字段库

运营维护可复用字段。平台预置：

- `supplier_code`：供数方编码（库表路径必填，映射供数方主数据）  
- `org_id`：归属机构标识（本期必填）  

库表类标准拼装时必须勾选上述字段。

### 3.2 接入方案库

维护数据源类型、JDBC 连接、频次、增/全量、是否 IP 白名单。  
**禁止**在方案上绑定供数方（避免与「一方案多标准、多供方共用」冲突）。

### 3.3 接入标准与生效判定

- 标准 = 勾选字段 + 一个接入方案。  
- 生效优先级：机构供数配置绑定标准（启用）→ 机构范围启用标准 → 全局启用标准。  

### 3.4 IP 白名单

按供数方维护允许来源 IP。仅当方案开启白名单管控时强制校验。  
**不替代**来源厂商归属判定。

### 3.5 供数方 appkey

一供方一 key。**仅接口路径**用于鉴权，并作为该路径「来源厂商」权威来源。  
库表路径不使用 appkey。

### 3.6 来源厂商识别与落库打标（重点）

| 路径 | 权威依据 | 打标 |
|------|----------|------|
| 接口 | appkey → 供数方 | 来源厂商 = 该供数方 |
| 库表/JDBC | 行内 `supplier_code` → 供数方 | 来源厂商 = 该供数方 |

校验失败（无编码/编码未知/供方停用/无法归属机构等）→ 拒收，不落库。  
计入某机构统计：还须该机构在「机构供数配置」中勾选了该供数方。

可选运维加强（非归属权威）：共前置机时按 Schema/表前缀与编码一致做交叉校验。

### 3.7 既有模块

V8 统计类页面不因本条改交互目标；接入规范页需展示字段口径与识别说明。

## 四、数据结构与流向

### 4.1 关键实体

| 实体 | 要点 |
|------|------|
| 数据标准字段 | 含 supplier_code、org_id 等 |
| 接入方案 | JDBC/频次/白名单开关；无供数方外键 |
| 接入标准 | 字段列表 + 方案 |
| 机构供数配置 | 机构 × 供数方列表 × 绑定标准 |
| 供数方 | 编码、appkey、启停 |
| 落库副本 | 来源厂商、接收时间、归属机构 |

### 4.2 主数据流

```
字段库 + 方案库 + 白名单 + 供数方（编码/appkey）
  → 发布标准；机构配置供数方与绑定标准
  → 机构下载生效标准转交供方
  → 送数：接口(appkey) 或 库表(supplier_code)
  → 识别厂商 + 校验 → 落库打标
```

## 五、边界情况处理

| 场景 | 处理 |
|------|------|
| 库表无 supplier_code / 编码未知 | 拒收，不落库 |
| 接口 appkey 无效 | 拒收，不落库 |
| 方案未开白名单 | 不校验 IP |
| 开了白名单但 IP 未登记 | 拒收 |
| 机构未配置该供数方 | 不计入该机构统计（可拒收无有效机构归属记录） |
| 试图在方案上绑厂商 | 产品不允许；文档列为不做 |

---

## 六、验收要点

1. 字段库含供数方编码；库表标准必含该字段。  
2. 方案无「绑定供数方」。  
3. 接口落库来源厂商 = appkey 对应供方。  
4. 库表落库来源厂商 = supplier_code 对应供方。  
5. V8 接入规范可看到字段与识别说明。
