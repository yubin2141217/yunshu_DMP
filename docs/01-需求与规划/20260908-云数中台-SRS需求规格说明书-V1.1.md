## 二、项目概述

### 2.1 项目背景

多厂商供数需要统一进入云数中台。领导沟通后，本期优先保证**数据能安全汇总落库**；分析统计深化后置。**已有统计与供数配置等模块保持当前内容不变**。在 V1.0「单份标准文档 + 入库量查看」基础上，标准改为可拼装的全局/机构标准，并增加推送安全与自动打标。

### 2.2 项目建设目标

1. 维护元数据字段库与接入方案库，拼装发布全局标准；机构可覆盖为机构标准。  
2. 机构预览/下载本机构生效标准并转交供数方。  
3. 供数方凭 appkey 推送；当生效标准绑定的接入方案开启白名单时，来源 IP 须在白名单内。  
4. 校验通过后单独落一份副本，自动标注来源厂商、接收时间，并归属机构。  
5. 既有概览、供数统计等能力保持 V1.0 规格不变。  

### 2.3 建设范围

**系统端**：V8 应用端、MT 管理端、供数方推送接收能力。

**本期功能**：

- 新增/强化：字段库、接入方案库、接入标准拼装（全局/机构）、IP 白名单、供数方 appkey、推送落库与自动打标、V8 生效标准预览下载  
- 保持不变：数据概览、供数统计、供数方查看、供数方管理、机构供数配置（见 V1.0）  
- 预留：不区分机构的自有供数通道、数据外推实装  

### 2.4 术语

| 统一用语 | 含义 |
|---------|------|
| 生效标准 | 机构有启用中的机构标准则用机构标准，否则用当前启用的全局标准 |
| 数据标准块 | 标准中勾选的元数据字段集合 |
| 接入方案 | 推送策略（含是否 IP 白名单管控） |
| appkey | 一供数方一份推送凭证 |
| 落库副本 | 推送成功后单独保存的一份数据 |

### 3.5.4 接入规范（V8 · 生效标准）

**（一）功能需求概述**

机构管理员查看并下载本机构**生效标准**（数据标准块 + 接入方案信息），转交供数方按标准推送。

**（二）功能设计**

**查看**

| 字段 | 说明 |
|------|------|
| 生效范围 | 机构标准或全局标准 |
| 数据标准 | 标准中勾选字段及属性摘要 |
| 接入方案 | 所绑方案的前置机、频次、增/全量、是否白名单管控等 |
| 发布时间 | 该生效标准的发布时间 |

**下载 / 预览**

提供预览与下载。无任何可用生效标准（全局未启用且无机构标准）时，不提供下载，提示联系平台运营。

**业务规则**

- 生效标准判定：有该机构启用中的机构标准则用机构标准，否则用当前启用的全局标准。无单独提示。  
- 各机构互不影响；仅本机构管理员可见本机构生效结果。无单独提示。  

**边界与异常**

- **空数据**：无生效标准 → 提示尚未发布，请联系平台运营  
- **权限不足**：平台运营在 V8 无此入口（不展示）  

### 3.5.7 元数据字段库

**（一）功能需求概述**

平台运营维护可复用元数据字段，作为拼装接入标准时「数据标准」块的素材。

**（二）功能设计**

**列表与维护**

| 字段 | 说明 |
|------|------|
| 字段名 | 业务可读名称 |
| 业务含义 | 口径说明 |
| 类型 | 数据类型 |
| 状态 | 启用 / 停用 |

支持新增、编辑、启用/停用。停用后不可被新标准勾选；已被标准引用的历史标准展示不受影响。

**边界与异常**

- **空列表**：提示暂无字段，请先新增  

### 3.5.8 接入方案管理

**（一）功能需求概述**

平台运营维护推送对接策略，供接入标准绑定。

**（二）功能设计**

| 字段 | 说明 |
|------|------|
| 方案名称 | 业务名称 |
| 前置机 | 地址与端口等 |
| 推送频次 | 如实时 / 每日等 |
| 更新规则 | 增量 / 全量及增量字段等 |
| 是否需要 IP 白名单管控 | 是 / 否 |
| 状态 | 启用 / 停用 |

停用后不可被新标准绑定。

**业务规则**

- 当「是否需要 IP 白名单管控」为是时，使用绑定该方案的生效标准进行推送，必须通过 IP 白名单校验。无单独提示。  

### 3.5.9 接入标准管理（全局 / 机构拼装）

**（一）功能需求概述**

平台运营拼装并发布全局或机构接入标准：勾选字段库中的启用字段，绑定一个启用中的接入方案。

**（二）功能设计**

**标准属性**

| 字段 | 说明 |
|------|------|
| 标准名称 | 业务名称 |
| 范围 | 全局 / 指定机构 |
| 数据标准块 | 勾选的字段列表 |
| 接入方案 | 绑定的一个方案 |
| 状态 | 启用 / 停用 |
| 发布时间 | 启用或发布时间 |

**启用规则**

- 全局：同时至多一份启用中的全局标准（新启用时原全局启用标准改为停用）。  
- 机构：同一机构同时至多一份启用中的机构标准。  

**业务规则**

- 创建时必须至少勾选一个启用字段，且必须绑定一个启用中的接入方案。提交失败时提示补全。  
- 机构生效标准见 3.5.4。无单独提示。  

**边界与异常**

- **无启用字段或方案可选**：提示先至字段库或接入方案管理启用  

### 3.5.10 IP 白名单管理

**（一）功能需求概述**

平台运营维护允许向云数中台推送的来源 IP。仅在生效标准所绑接入方案开启白名单管控时参与校验。

**（二）功能设计**

支持新增、删除（或停用）白名单记录。列表展示已登记 IP。

**业务规则**

- 推送时若需白名单管控：来源 IP 未命中白名单 → 拒收，不落库。无单独对机构提示。  
- 未开启白名单管控时，不因 IP 拒绝。无单独提示。  

### 3.5.11 供数方 appkey

**（一）功能需求概述**

在供数方上维护一供方一 appkey，用于推送鉴权。

**（二）功能设计**

| 能力 | 说明 |
|------|------|
| 查看 / 发放 | 为供数方生成或登记 appkey |
| 轮换 | 轮换后旧 key 失效 |

**业务规则**

- 推送必须携带有效 appkey，且对应供数方为启用。否则拒收，不落库。无单独提示。  

### 3.5.12 推送接收、落库副本与自动打标

**（一）功能需求概述**

接收供数方按生效标准推送的数据；校验通过后单独保存一份副本，并自动打标。

**（二）功能设计**

**校验顺序（逻辑）**

1. appkey 有效且供数方启用  
2. 若生效标准绑定方案要求白名单：来源 IP 在白名单中  
3. 能解析归属机构（本期仅支持区分机构）  
4. 报文满足生效标准数据标准块的必填口径（细则在联调说明书约定）  

**落库与打标**

| 项 | 说明 |
|----|------|
| 落库副本 | 校验通过后保存一份，与供方侧原始推送对应 |
| 来源厂商 | 自动取自 appkey 对应供数方 |
| 接收时间 | 自动取进入中台的时间 |
| 归属机构 | 自动取解析到的机构 |
| 预留 | 数据域类型（区分机构/不区分机构）、外推状态 |

**业务规则**

- 任一校验失败：拒收，不写落库副本。无单独提示（可由接收回执说明原因，回执形态联调约定）。  
- 本期不提供「不区分机构」成功落库通道。无单独提示。  
- 自动打标无需人工配置。无单独提示。  
- 数据外推本期不执行，仅预留扩展。无单独提示。  

**边界与异常**

- **无法归属机构**：拒收  
- **无生效标准**：拒收  

**（三）业务逻辑关联**

- 依赖字段库、接入方案、标准启用、白名单、供数方 appkey  
- 落库结果可供 V1.0 既有入库统计在数据具备后按原口径使用（统计模块本身本期不改规格）

## 四、非功能需求

| 项 | 要求 |
|----|------|
| 安全 | 鉴权或白名单失败不得落库 |
| 一致 | 同一生效标准下，机构多次预览/下载内容一致 |
| 追溯 | 落库副本可区分来源厂商与接收时间 |

---

## 五、验收标准

1. 可维护字段、接入方案（含白名单开关）、全局/机构标准并启用。  
2. 机构有机构标准时下载机构标准，否则下载全局标准。  
3. 合法 appkey +（若需要）白名单 IP 推送成功，落库含来源厂商、接收时间、归属机构。  
4. appkey 无效、或需白名单但 IP 未登记、或无法归属机构时推送失败且不落库。  
5. 数据概览、供数统计等既有模块仍按 V1.0 可用，无破坏性改版。
