# 云数中台接入标准（示例）

| 项 | 内容 |
|----|------|
| 文档编号 | YSZT-STD-001 |
| 版本 | V1.0（示例） |
| 适用范围 | 向云数中台送数的全部供数方（含康奈及外部厂商） |
| 生效方式 | 全平台当前一份；替换后立即生效 |

本文档供机构下载后转交供数方。供数方按本标准组织数据并送入中台。中台按标准保存原文与元数据；机构侧核验入库条数，不在本期查阅正文。

---

## 一、需要接入哪些数据

一期接入的是**舆情原文及相关附属信息**。供数方须按下面清单提供，缺必接项则该条无法按标准入库。

| 序号 | 数据名称 | 数据分类 | 是否必接 | 说明 |
|------|----------|----------|----------|------|
| 1 | 舆情文章主数据 | 库表数据集 | 必接 | 一条文章一条记录，含供数方、归属机构、标题、区域、原文地址、内容时间等 |
| 2 | 供数方与机构对照 | 库表数据集 | 必接 | 供数方编码、机构标识须与中台已登记值一致，否则该条不入库 |
| 3 | 区域字典 | 库表数据集 | 建议 | 区域代码与名称对照，随主数据一并保存，本期界面不按区域切片 |
| 4 | 文章正文 | 非结构化数据 | 必接 | 原文正文；无正文时可空，中台记为无正文，仍计一条（若其它必填满足） |
| 5 | 原文快照 / 附件 | 非结构化数据 | 可选 | 网页快照、配图、附件等，须能回挂到主数据主键 |
| 6 | 文章推送 | 接口数据 | 必接 | 供数方调用中台接收接口（或中台按约定拉取），完成送数 |
| 7 | 入库回执 | 接口数据 | 建议 | 中台返回接收结果（是否保存、是否计入该机构），供双方对账 |

**公共必填（无论走库表、文件还是接口，每条业务数据都要能落到这些字段）：**

| 字段 | 必填 | 口径 |
|------|------|------|
| 供数方编码 | 是 | 与中台「供数方管理」中的编码一致 |
| 归属机构标识 | 是 | 一条只归属一个机构；多机构须分多次按各机构标识送来 |
| 到达中台时间 | 是 | 进入中台的时间；缺失则由中台写入当前时间 |
| 标题 | 否 | 空则记为「（无标题）」 |
| 正文 | 否 | 本期两端不提供查阅 |
| 原文地址 | 否 | 供数方侧原文 URL 或内部编号 |
| 内容时间 | 否 | 内容发布时间 |
| 区域 | 否 | 随原文保存，本期不做界面筛选 |

## 二、数据分类

送数时须标明本批数据属于哪一类。三类可以组合出现（例如接口推送一条库表记录，同时带正文文件）。

| 分类 | 定义 | 典型形态 | 在本中台中的用途 |
|------|------|----------|------------------|
| 库表数据集 | 二维结构化记录，字段固定、可按行入库 | 数据表、CSV/Excel 批量、库到库同步 | 文章主数据、字典、对照关系 |
| 非结构化数据 | 不以固定二维表表达的对象 | 正文文本、HTML、PDF、图片、附件包 | 正文与快照，回挂主数据 |
| 接口数据 | 通过服务调用传输的实时或准实时报文 | REST/HTTPS JSON（本期推荐） | 推送入库、回执、对账 |

分类判定：有稳定字段、一行一条业务对象 → **库表数据集**；以文件或大文本为主体、字段无法拆成稳定列 → **非结构化数据**；以在线调用完成交换 → **接口数据**（报文内部仍须满足对应分类的元数据）。

---

## 三、各类元数据标准

元数据分两层：**资源级**（这一批/这一张表/这一个接口是什么）和 **元素级**（每个字段或每个文件属性）。未按下列必填项提供元数据的，中台可拒收该批次。

### 3.1 库表数据集

**资源级元数据（一张表或一个数据集填一次）**

| 元数据项 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 数据集中文名 | 是 | 业务可读名称 | 舆情文章主数据 |
| 数据集编码 | 是 | 全局唯一，建议 `YSZT_T_` 前缀 | YSZT_T_ARTICLE |
| 数据分类 | 是 | 固定填「库表数据集」 | 库表数据集 |
| 主题 | 是 | 本期为舆情 | 舆情 |
| 提供方 | 是 | 供数方名称 + 编码 | 康奈 / KN001 |
| 更新周期 | 是 | 实时 / 小时 / 日 / 一次性 | 实时 |
| 主键 | 是 | 供数方侧业务主键，用于回挂正文 | article_id |
| 增量字段 | 建议 | 用于增量抽取 | content_time 或 arrive_time |
| 字符集 | 是 | 推荐 UTF-8 | UTF-8 |
| 记录口径 | 是 | 一行代表什么 | 一条舆情原文 |

**元素级元数据（每个字段一行）**

| 元数据项 | 必填 | 说明 |
|----------|------|------|
| 字段中文名 | 是 | 与业务口径一致 |
| 字段英文名 | 是 | 小写字母+下划线 |
| 数据类型 | 是 | string / int / datetime / text 等 |
| 长度或精度 | 是 | 如 string(128)、datetime |
| 是否主键 | 是 | 是 / 否 |
| 是否必填 | 是 | 是 / 否 |
| 值域或字典 | 建议 | 枚举、代码表名称 |
| 示例值 | 建议 | 便于联调 |
| 备注 | 否 | 特殊规则 |

**示例：舆情文章主数据字段**

| 字段中文名 | 字段英文名 | 类型 | 必填 | 说明 |
|------------|------------|------|------|------|
| 供数方侧文章编号 | article_id | string(64) | 是 | 供数方主键 |
| 供数方编码 | supplier_code | string(32) | 是 | 对应中台供数方编码 |
| 归属机构标识 | org_id | string(64) | 是 | 对应中台机构 |
| 区域代码 | region_code | string(32) | 否 | 建议同时给区域名称 |
| 区域名称 | region_name | string(64) | 否 | |
| 标题 | title | string(512) | 否 | |
| 原文地址 | source_url | string(1024) | 否 | |
| 内容时间 | content_time | datetime | 否 | yyyy-MM-dd HH:mm:ss |
| 正文引用 | content_ref | string(256) | 否 | 指向非结构化对象 ID；若正文随接口直传可空 |

### 3.2 非结构化数据

**资源级元数据**

| 元数据项 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 资源中文名 | 是 | | 舆情文章正文 |
| 资源编码 | 是 | 建议 `YSZT_U_` 前缀 | YSZT_U_CONTENT |
| 数据分类 | 是 | 固定填「非结构化数据」 | 非结构化数据 |
| 对象类型 | 是 | 正文 / 快照 / 图片 / 附件 | 正文 |
| 允许格式 | 是 | 扩展名或 MIME | txt、html、utf-8 文本 |
| 大小上限 | 是 | 单对象上限 | 正文 2 MB；附件 20 MB |
| 编码 | 是 | 文本类必填 | UTF-8 |
| 关联主键 | 是 | 回挂库表哪条记录 | article_id + supplier_code |
| 提供方 | 是 | | 与主数据同一供数方 |
| 密级 | 建议 | 按机构侧要求 | 内部 |

**元素级元数据（每个对象实例）**

| 元数据项 | 必填 | 说明 |
|----------|------|------|
| 对象 ID | 是 | 供数方侧唯一 |
| 文件名 | 是 | 含扩展名 |
| 格式 | 是 | html / txt / pdf / jpg 等 |
| 字节大小 | 是 | 正整数 |
| 校验值 | 建议 | MD5 或 SHA-256，用于完整性 |
| 关联文章编号 | 是 | 必须能落到库表主键 |
| 摘要 | 否 | 前 200 字，便于对账，不等于开放查阅正文 |

**示例约定**

- 正文优先 UTF-8 纯文本或 HTML；不在元数据里拆段落、不要求中台做研判字段。
- 图片、PDF 等附件为可选；没有附件不影响主数据入库。
- 非结构化对象不能单独计入机构统计：必须挂到一条有效的库表主数据上，才计入该机构入库条数。

### 3.3 接口数据

**资源级元数据（一个接口填一次）**

| 元数据项 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 接口中文名 | 是 | | 舆情文章推送 |
| 接口编码 | 是 | 建议 `YSZT_A_` 前缀 | YSZT_A_ARTICLE_PUSH |
| 数据分类 | 是 | 固定填「接口数据」 | 接口数据 |
| 调用方向 | 是 | 供数方推送 / 中台拉取 | 供数方推送 |
| 协议 | 是 | 本期 HTTPS + JSON | HTTPS |
| 方法与路径 | 是 | | POST /api/v1/articles |
| 鉴权方式 | 是 | Token / 签名，联调时下发 | Header: Authorization |
| 超时 | 建议 | | 30 秒 |
| 调用频次 | 建议 | 防止压垮接收端 | ≤ 20 次/秒/供数方 |
| 幂等键 | 是 | 本期重复送达仍分别计数，但须能识别 | article_id + supplier_code |
| 字符集 | 是 | | UTF-8 |

**元素级元数据（请求 / 响应每个参数一行）**

| 元数据项 | 必填 | 说明 |
|----------|------|------|
| 参数位置 | 是 | Header / Query / Body |
| 参数中文名 | 是 | |
| 参数英文名 | 是 | |
| 数据类型 | 是 | |
| 是否必填 | 是 | |
| 说明与示例 | 是 | |

**示例：文章推送请求体（Body）**

| 参数中文名 | 参数英文名 | 类型 | 必填 | 说明 |
|------------|------------|------|------|------|
| 供数方编码 | supplierCode | string | 是 | |
| 归属机构标识 | orgId | string | 是 | |
| 文章编号 | articleId | string | 是 | 供数方主键 |
| 标题 | title | string | 否 | |
| 区域代码 | regionCode | string | 否 | |
| 区域名称 | regionName | string | 否 | |
| 原文地址 | sourceUrl | string | 否 | |
| 内容时间 | contentTime | string | 否 | yyyy-MM-dd HH:mm:ss |
| 正文 | content | string | 否 | 非结构化正文直接放此字段，或只传 contentRef |
| 正文对象引用 | contentRef | string | 否 | 已通过文件通道上传时填写 |

**示例：入库回执（响应）**

| 参数中文名 | 参数英文名 | 说明 |
|------------|------------|------|
| 是否已保存原文 | accepted | true 表示中台已按标准落库 |
| 是否计入该机构 | counted | 供数方已启用且该机构已配置时为 true |
| 到达中台时间 | arriveTime | 中台写入 |
| 失败原因 | message | 编码无法对应等 |

接口报文中的业务字段，须同时满足 **3.1 库表** 与 **3.2 非结构化** 的必填口径；接口元数据只补充「怎么传」，不替代「传什么」。

## 四、送数与计入（供联调对照）

1. 供数方编码或机构标识无法对应 → **整条不入库**。  
2. 供数方已启用，且该机构已配置该供数方 → **计入**该机构概览与供数统计。  
3. 未配置或供数方停用 → **原文仍保存，不计入该机构新数据**。  
4. 同一原文地址被不同供数方送来 → **分别计数**，本期不合并。  
5. 同一供数方重复送来同一原文地址 → **分别计数**，本期不覆盖。

## 五、文档使用说明

机构管理员在 V8「接入规范」下载本文档，转交供数厂商。平台运营在 MT「接入标准管理」维护全平台当前这一份文件。本文为示例稿，字段名称在正式联调前可按接口说明书微调，**分类方式与必填口径以中台公布的当前档为准**。
