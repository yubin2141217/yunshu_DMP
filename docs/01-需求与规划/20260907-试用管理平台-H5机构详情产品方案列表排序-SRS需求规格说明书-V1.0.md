## 二、项目概述

### 2.1 项目背景

试用管理平台 H5 为销售提供机构统计与试用跟进能力。销售常从「申请中机构」「试用中机构」等分类进入机构详情，查看该机构下多个产品方案。若列表不按入口意图排序，目标状态方案可能沉在下方，增加查找成本。本期在不改变机构列表筛选口径的前提下，仅优化机构详情产品方案列表的排序规则。

### 2.2 建设目标

1. 从某状态统计分类进入机构详情时，该状态产品方案置顶展示。  
2. 置顶组与非置顶组均按方案最近写操作时间倒序。  
3. 从机构总数进入或无入口状态时，仅按最近写操作时间倒序。  

### 2.3 术语

| 统一用语 | 含义 |
|---------|------|
| preferStatus | 进入机构详情时携带的入口意图状态；为空表示不按状态置顶 |
| 更新时间 / updatedAt | 产品方案记录最近一次写操作或保存的时间 |
| 置顶组 | status 与 preferStatus 完全相同的产品方案集合 |
| 严格单状态 | 置顶仅匹配单一状态值，不扩展为列表筛选的复合口径 |

## 三、功能需求

### 3.1 功能菜单

本期不新增一级菜单。沿用 H5：

- 机构统计（一级）  
  - 机构列表（下钻）  
  - 机构详情（下钻）  
  - 方案详情（下钻，本期排序规则不作用于本页列表结构变更）

### 3.2 需求清单

| 模块 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| 入口透传 | 列表进入详情携带 preferStatus | 高 | all 映射为空 |
| 方案排序 | 状态置顶 + 更新时间倒序 | 高 | 严格单状态 |
| 详情查询 | 支持 preferStatus，返回已排序列表 | 高 | 排序由服务端完成 |

### 3.3 页面清单

| 页面 | 说明 | 本期变更 |
|------|------|----------|
| 机构统计 | 状态卡片入口 | 无界面变更；下钻参数延续 |
| 机构列表 | 按 filter 展示机构 | 进入详情时透传 preferStatus |
| 机构详情 | 展示机构信息与产品方案列表 | 列表按规则排序展示 |
| 方案详情 | 单方案详情 | 无排序相关变更 |

### 3.4 权限

| 功能 | 销售（H5） |
|------|------------|
| 查看机构详情产品方案列表 | 有（限其统计单元可见范围，口径同现网） |
| 手动改排序 | 无 |

### 3.5 功能详细设计

### 3.5.1 入口状态透传

**（一）功能需求概述**

销售从机构统计某分类进入机构列表，再进入机构详情时，系统须保留本次下钻的意图状态，供产品方案列表排序使用。

**（二）功能设计**

**透传字段**

| 字段名称 | 类型 | 说明 |
|---------|------|------|
| preferStatus | 枚举或空 | 空 / 申请中 / 试用中 / 即将到期 / 已到期 / 冷冻期 |

**映射规则**

| 统计入口 / 列表 filter | preferStatus |
|------------------------|--------------|
| 机构总数 / all | 空 |
| 申请中 | 申请中 |
| 试用中 | 试用中 |
| 即将到期 | 即将到期 |
| 已到期（已停止试用机构） | 已到期 |
| 冷冻期 | 冷冻期 |

**业务规则**

- 机构列表进入机构详情时必须按上表写入 preferStatus。无单独提示。  
- 销售通过收藏或分享等方式直接打开机构详情且未带 preferStatus 时，按空处理。无单独提示。  

**边界与异常**

- **参数非法**：无法识别的 preferStatus 按空处理  
- **权限不足**：不可见机构时，按现有机构详情无权或无数据处理，不单独因排序提示  

**（三）业务逻辑关联**

- 依赖机构统计与机构列表既有下钻路径  
- 为 3.5.2、3.5.3 提供 preferStatus  

### 3.5.2 产品方案列表排序

**（一）功能需求概述**

机构详情中的产品方案列表按入口意图与最近写操作时间排序，使销售优先看到与本次下钻相关的方案。

**（二）功能设计**

**排序规则**

| 条件 | 排序结果 |
|------|----------|
| preferStatus 为空 | 全部产品方案按更新时间倒序 |
| preferStatus 非空 | 先输出状态等于 preferStatus 的方案（组内更新时间倒序），再输出其余方案（组内更新时间倒序） |
| 更新时间相同 | 按方案标识倒序，保证次序稳定 |
| 置顶组无数据 | 等同 preferStatus 为空 |

**置顶对照（严格单状态）**

| preferStatus | 置顶的方案状态 |
|--------------|----------------|
| 申请中 | 仅申请中 |
| 试用中 | 仅试用中（不含即将到期） |
| 即将到期 | 仅即将到期 |
| 已到期 | 仅已到期（不含停用） |
| 冷冻期 | 仅冷冻期 |

**更新时间**

| 字段名称 | 类型 | 说明 |
|---------|------|------|
| 更新时间 | 日期时间 | 该产品方案记录最近一次写操作或保存时间；延期、关停、重置、更换产品方案、申请审核与处理等写操作均刷新 |

**展示**

- 列表仍以产品方案卡片逐条展示；点击进入方案详情的既有行为不变。  
- 本期不提供排序方式切换，不要求在卡片上展示更新时间。  

**业务规则**

- 置顶为状态完全相等匹配，不采用机构列表「试用中含即将到期」的复合筛选口径。无单独提示。  
- 机构列表的筛选与计数口径本期不变。无单独提示。  

**边界与异常**

- **空数据**：机构无任何产品方案时，显示现有空态说明（如暂无数据）  
- **仅有非置顶方案**：整表按更新时间倒序展示  

**（三）业务逻辑关联**

- 依赖 preferStatus 透传与方案更新时间维护  
- 列表顺序以详情查询返回顺序为准  

### 3.5.3 机构详情查询（含排序）

**（一）功能需求概述**

查询指定机构的详情及下属产品方案列表时，可传入 preferStatus；返回的产品方案列表须已按 3.5.2 完成排序。

**（二）功能设计**

**查询条件**

| 条件 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 机构标识 | 标识 | 是 | 待查看的机构 |
| preferStatus | 枚举或空 | 否 | 空表示不按状态置顶 |

**返回内容**

| 内容 | 说明 |
|------|------|
| 机构基本信息 | 名称、所属销售等，口径同现网 |
| 产品方案列表 | 该机构可见范围内的产品方案，已按 3.5.2 排序 |

**业务规则**

- 排序在服务端完成。客户端按返回顺序展示，不自行重排。无单独提示。  
- 未传 preferStatus 时，按空处理。无单独提示。  

**边界与异常**

- **机构不存在或不可见**：按现有详情失败或空数据处理  
- **preferStatus 非法**：按空处理并返回仅按更新时间倒序的列表  

**（三）业务逻辑关联**

- 产品方案状态与更新时间来源于试用/申请相关写操作落库结果  
- 与 3.5.1、3.5.2 共同构成完整排序能力

## 四、非功能需求

| 项 | 要求 |
|----|------|
| 一致性 | 相同 preferStatus 与相同数据下，多次进入详情列表顺序一致 |
| 时效 | 写操作刷新更新时间后，再次进入详情可见排序变化 |
| 兼容 | 不传 preferStatus 时行为为全量按更新时间倒序 |

## 五、验收标准

1. 从申请中机构进入详情：所有申请中方案位于列表顶部，组内更新时间由新到旧；其余方案位于下方并按更新时间由新到旧。  
2. 从试用中机构进入详情：即将到期方案不进入置顶组。  
3. 从机构总数进入详情：不出现状态置顶，仅按更新时间由新到旧。  
4. 对某方案执行延期等写操作后，该方案在其所属组内位置随更新时间正确上移。  
5. 直接打开机构详情且未带 preferStatus：仅按更新时间由新到旧。

## 六、本期不做

- 调整机构列表的排序或筛选复合口径  
- 在产品方案卡片上展示更新时间  
- 提供用户可切换的排序方式  
- Web 管理端机构详情同步改造
