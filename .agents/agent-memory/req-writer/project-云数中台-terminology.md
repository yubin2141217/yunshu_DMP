# 云数中台 · 业务术语表

| 统一用语 | 含义 | 禁止混用 |
|---------|------|---------|
| 云数中台 | 本产品名称 | 数据中台（单独指代时需写全称） |
| V8 应用端 | 机构用户使用的应用端 | 前台、H5、移动端 |
| MT 管理端 | 我司运营人员使用的管理端 | 后台（可与 MT 管理端并列说明） |
| 机构 | 租户单位，数据按机构隔离 | 客户、租户（叙述时「机构租户」可用） |
| 机构管理员 | 本期机构侧唯一业务角色 | 研判员（后期） |
| 平台运营 | 我司在 MT 使用本产品的角色 | 管理员（易与机构管理员混淆） |
| 供数方 | 向中台送数的来源厂商（如清博智能、智慧星光等） | 仅口语可用「厂商」，文档统一称供数方 |
| 供数方编码 | 供数方主数据唯一编码；库表行内 `supplier_code` 须与之对应以识别来源厂商 | 用 appkey 代替库表路径识别 |
| appkey | 一供数方一份接口推送凭证；仅接口路径鉴权与来源识别 | 库表路径凭证 |
| 接入规范 | V8 侧供机构下载的生效标准菜单名 | 接入标准（MT 侧管理菜单） |
| 接入标准 | 勾选字段 + 绑定接入方案后发布的标准 | API 文档 |
| 接入方案 | 可复用对接策略（JDBC/频次/白名单等），不绑定供数方 | 适用供数方方案 |
| 供数配置 | 运营指定某机构可接收哪些供数方 | 开通、订阅（本期不用开通） |
| 入库 | 数据按标准进入中台并保存原文 | 推送（指供数方送来）、落库（可用入库） |
| 启用/停用 | 供数方状态 | 开启/关闭、正常/禁用 |
| 新增 | 新增供数方等 | 添加、创建 |
| 编辑 | 编辑已有记录 | 修改、更新 |
| 删除 | 删除记录 | 移除、清除 |
| 区域 | 舆情数据元数据字段，本期入库不在机构端切片展示 | 地区（与区域统一用区域） |
