本技能指导创建具有鲜明个性、生产级品质的前端界面，避免泛滥的「AI 廉价感」审美。实现真正可运行的代码，并对美学细节与创意取舍投入极高关注。

用户会提供前端需求：要构建的组件、页面、应用或界面。他们可能补充用途、受众或技术约束等上下文。

## 适用范围边界

**在 prototype-demo 中的优先级**：已选 Style（`style.md` + 预览）与 `component.md` **高于**本文。禁止用本文「另选大胆美学」推翻已定色板、字体栈或预览组件基线；仅在 Style 边界内做气质与编排。

当本文档与企业官网、服务落地页、产品营销页或其他转化导向的 WEB 页面的结构规范或组件规范一并使用时：
- 将本文档视为视觉方向指南，而非内容层级、语义结构、对齐纪律或转化逻辑的替代品。
- 若另有规范已定义信息架构、容器宽度、组件一致性、响应式、CTA 层级或交互约束，优先遵循那些要求。
- 在允许的系统边界内使用大胆的视觉语言；不要为了新颖性而破坏可读性、栅格稳定性、内容密度控制或核心转化路径。
- 仅当与页面的业务语境和可用性要求兼容时，才鼓励鲜明的字体、装饰细节、不对称、动效与氛围化背景。
- **已选定 `.style` 时**：字体与主色以 Style/预览为准；动效时长与缓动用 Style Motion tokens；本文只强化层次与细节，不换肤。

## 设计思考

编码之前，先理解语境，并坚定选择一个大胆的美学方向：
- **目的**：这个界面解决什么问题？谁在使用？
- **调性**：选一个极端方向：极致极简、极繁混沌、复古未来、有机/自然、奢华/精致、玩趣/玩具感、编辑/杂志风、粗野/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。可选风格很多。用它们做灵感，但最终设计必须忠实于既定美学方向。
- **约束**：技术要求（框架、性能、无障碍）。
- **差异化**：什么让它令人难忘？别人会记住的那一件事是什么？

**关键**：选定清晰的概念方向，并精准执行。大胆极繁与克制极简都成立——关键是意图明确，而非强度本身。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），并做到：
- 生产级且功能可用
- 视觉冲击力强、令人难忘
- 统一、有清晰的美学观点
- 每个细节都精雕细琢

## 前端美学指南

重点关注：
- **字体排印**：选择美观、独特、有趣的字体。优先具有辨识度、能提升前端美学且贴合品牌语境的选型。若配套的结构规范已为企业可读性或本地化规定了基础字体体系，则保留该基础体系，通过克制的展示字体或层级处理注入个性，而不是破坏一致性。
- **色彩与主题**：坚持统一的美学。用 CSS 变量保证一致性。主色明确、强调色锐利，优于胆怯、平均分散的配色。
- **动效**：用动画做效果与微交互。HTML 场景优先纯 CSS 方案。React 可用时使用 Motion 库。聚焦高影响力时刻：一次编排良好、带交错显现（animation-delay）的页面加载，比零散的微交互更能带来愉悦感。使用滚动触发与能制造惊喜的悬停状态。
- **空间构图**：出人意料的布局。不对称。叠压。对角流动。打破栅格的元素。慷慨的留白，或受控的密度。
- **背景与视觉细节**：营造氛围与层次，而不是默认纯色。加入与整体美学匹配的情境化效果与纹理。可运用渐变网格、噪点纹理、几何图案、分层透明、戏剧性阴影、装饰边框、自定义光标、颗粒叠加等创意形式。

绝不使用泛滥的 AI 生成审美，例如过度使用的字体族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色（尤其是白底紫渐变）、可预测的布局与组件模式，以及缺乏具体语境个性的模板化设计。

创造性地解读需求，做出真正为语境定制的意外选择。没有两套设计该一模一样。在浅色与深色主题、不同字体、不同美学之间变化。绝不要在多次生成中收敛到常见选项（例如 Space Grotesk）。

**重要**：让实现复杂度匹配美学愿景。极繁设计需要详尽的代码，以及大量动画与效果。极简或精致设计需要克制、精准，以及对间距、字体与微妙细节的细心处理。优雅来自把愿景执行到位。
